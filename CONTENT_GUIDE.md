# SUSTech 2026 Wiki Content Guide

This first release is an English editorial framework. Dry-lab pages contain
checked-in project material; pages marked **Content pending team review** are
structured shells and must be completed by the responsible team members.

## ORCA visual identity

The new scroll-story homepage is documented in [ORCA_HOMEPAGE.md](docs/ORCA_HOMEPAGE.md).
Its settled hero directly displays the complete left panel of the original
`visual-system-reference.jpg`, proportionally scaled. The entrance whale comes
from beside the title in that same reference, not a separate fish design.
The original brain, title, whale and neural tail are not redrawn or rearranged.
The descriptions below of the original two crops and eight swatches remain relevant
to the earlier shared visual system, not the new homepage timeline.

The visible project name is **ORCA**, expanded as **On-target RNA Correction
for Alzheimer’s Disease**. The homepage translates the team reference artwork
into a responsive web composition. The two whale images are deterministic crops
from the team-provided high-resolution companion to `wiki1.png`; they preserve
the original artwork instead of redrawing the animals in CSS or SVG. Currents,
coral and bubbles remain lightweight decorative web elements.

The eight swatches sampled from `wiki1.png` are slate `#2E3065`, coral
`#F2989F`, periwinkle `#9B9EF7`, current blue `#5F62CD`, indigo `#3D409B`,
abyss `#191A59`, pale lavender `#D6D8FF` and violet `#6F71C1`. White
`#FFFFFF` is the primary reading canvas and coral is the primary accent.
Georgia Bold is the display face; a local Futura Medium-compatible stack is
used for body text without loading third-party fonts.

Some reproducibility links and commands contain `REWIRE` inside historical
source-directory names. Do not rename those literal paths unless the public
source repository is migrated at the same time; they are provenance, not the
current project brand.

## Local workflow

Use the existing Conda environment:

```bash
conda activate xbx_env
python -m pip install -r dependencies.txt
python -m unittest discover -s tests -v
python -m flask --app app.py freeze
python scripts/audit_build.py
python -m flask --app app run --host 127.0.0.1 --port 8080
```

The development server runs at `http://127.0.0.1:8080`.

- Page images: `assets/images/`, referenced as `/assets/images/file-name.webp`

  `brain-delivery.html`, `offtarget-atlas.html` and `software.html`

Do not modify `LICENSE` or remove the license and repository links from the footer.

## Evidence labels

Every quantitative or scientific statement must use the appropriate status:

- **Simulation output** — generated by a named model run; not measured.
- **Heuristic prioritization** — a ranked lead; not a probability or confirmed event.
- **Experimental data** — only after the team verifies the assay, controls and source file.
- **Implemented software** — describes tested functionality, not biological validation.

Never copy a model prediction into an experimental-results section without
changing both its wording and its evidence status.

Publication evidence snapshots for the displayed dry-lab numbers live under
`static/evidence/`. They supplement—rather than replace—the linked public
source repository and the responsible team member's review.

## Responsible AI and human review

The repository’s `.claude/RESPONSIBLE_AI_USE.md` is a publication gate, not a
suggestion. Before any commit or publication, a named team reviewer must:

1. Understand and be able to defend every scientific claim and code-mediated result.
2. Trace every number to a team file, approved database output or verified source.
3. Open every DOI/URL and verify authors, title, year and relevance.
4. Confirm that no quotation, result, attribution or team-member detail was invented.
5. Credit collaborators and complete the official Attributions Form accurately.
6. Remove credentials, personal data, private file paths and confidential material.
7. Review new dependencies and confirm that all media licenses permit publication.

AI-assisted prose is a draft until this review is complete. It must never be
presented as a real person’s quotation or as peer-reviewed fact.

The checked-in PNG crops are local design-review assets. Before publication,
approved images, photos, icons and fonts must be uploaded through the iGEM
uploads tool and served from `static.igem.wiki`. Videos must use iGEM Video
Universe; do not load final media from third-party CDNs.

For every asset, record alt text, caption, creator/source, license and the page
where it appears. The final orca scene represents hope and must not be described
as evidence that the project cures Alzheimer’s disease.
