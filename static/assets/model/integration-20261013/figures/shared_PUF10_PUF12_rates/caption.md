All 2,221 genomic allele keys retained in both PUF10 and PUF12 are linked by chromosome, position, REF and ALT. Each value is the existing median of four source replicate rates, converted from fraction to percent. Hexagons aggregate counts for display only (gridsize 36, fixed 0–100 axes); their counts sum to 2,221. Dashed line is equality. Delta is PUF12 minus PUF10, in percentage points, calculated per site before taking the median. Spearman uses average ranks and is descriptive; no p-value, uncertainty interval, sample-number pairing, regression, biological-replicate inference or new exclusion is applied. Selection in both positive lists conditions this result and excludes absent/missing sites rather than assigning zeros. It does not measure specificity, net reporter editing or a causal repeat-length effect.
