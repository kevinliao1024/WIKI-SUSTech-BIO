## Additional workflow · Section 4.3: LAMAR region selection and cytidine ranking
- Source path: `wiki/components/model/module4.html`
- Original URL: `/model#module4-strategy`
- SHA-256: `4438d7b315a5c92cb57faba267ca11ceac56c88096f5dc6d933d4fe31ec4184a`
- Preview: `figure-extra-lamar-two-stage.svg`
- Scope: The current application links Stage I region selection to Stage II ranking. Stage I outputs a probability of at least one RNA-seq-supported site; Stage II outputs a scalar editing-associated score. The design uses 1,024-nt windows with 128-nt overlap, although the evaluated data also include shorter regions. The reported Stage II evaluation scored cytidines in positive regions directly; the combined application is not presented as an evaluated end-to-end cascade.
