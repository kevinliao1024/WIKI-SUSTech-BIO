# Figure plan

Audience: readers of the public Dry Model page.
Purpose: review icon-based alternatives without replacing the mounted figures.

Style: original flat pictograms, ORCA indigo/teal/orange palette, warm-white canvas, Futura with Arial/DejaVu fallbacks. Each pictogram is drawn as vector geometry; the SVGs contain native editable text and zero embedded raster images. Arrows are explicit process relationships, not decorative connectors. Titles, captions, source attribution and scope notes remain outside the canvas.

Scope: six numbered workflow-bearing figures plus the unnumbered Section 4.3 formulation/two-stage workflow. Figure 33 retains quantitative panel B as an original-source panel; only A/C/D are redrawn. Quantitative plots elsewhere, the decorative typing hero and unmounted historical DBTL components are excluded.

The preview gallery embeds all original PNGs and generated SVGs, and needs no network or script to display. Download links refer to adjacent files. Original source links refer to the wiki paths. On narrow screens the vector canvas scrolls horizontally at a readable minimum width.

Validation: parse every SVG; confirm zero image nodes; detect label collisions and clipping using the actual renderer; inspect original/new images, then test the gallery in desktop and mobile browsers. No model reruns, threshold changes, data-panel redrawing or existing asset replacements.
