# Active Model artwork

The Model page uses these local generated PNGs:

- `orca-model-computing.png`: original seated character and source pixels for the animated gloves.
- `orca-model-typing-background.png`: the same scene with the gloves removed to provide a stationary animation background.
- `neuron-frame-multipolar.png`, `neuron-frame-bipolar.png`, `neuron-frame-pseudounipolar.png`, `neuron-frame-pyramidal.png`: transparent decorative neuron card frames.

Created with the built-in image generation tool using the team's Home artwork, `assets/hero/clearance/cleaners-ready.png`, as the identity/style reference. These illustrations are conceptual decoration, not model results or anatomical evidence. Original scientific text, formulas, and result figures remain unchanged.

The card characters reuse the original Home face with SVG limbs. Each visible arm is a continuous curve of equal thickness. Browser animation drives the magnifier, protein tap, planning card, and drawing actions. The title character uses separate original glove pixels over the generated background, without distortion filters. Reduced-motion preferences are supported.

Generation specifications: retain the Home indigo outlines, pastel palette and cartoon style; generate empty neuron-shaped frames without labels or invented results. For the typing background, preserve the original seated composition and remove only the two gloves, reconstructing the keyboard underneath. Do not redesign the character.

Validation: 32 project tests, static build and 24-route audit passed. Browser checks covered responsive widths, directory expansion without navigation, animation contact points, cursor completion, equal arm thickness, and stationary computer imagery.
