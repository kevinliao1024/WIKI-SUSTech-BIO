# ORCA 跨页探索足迹：设计讨论

日期：2026-10-13，Asia/Shanghai。状态：独立设计预览，未接入正式页面。

## 参考与已有基础

参考 [Fudan Visual Design](https://2026.igem.wiki/fudan/visual-design) 的 Page trail：页面区分未访问、已访问和当前访问，并允许重置历史。借鉴的是阅读足迹与整体视觉世界结合的方式。

ORCA 当前首页通过 `explore_slides.html` 提供五组、19 个导航页面。内页已有单页阅读进度组件。当前组件没有跨页访问记录，本提案也没有修改这些组件。

## 三个方向

1. **记忆星图，优先推荐。** 五组章节成为五个相连的小星群，每个页面是一点。未访问为空心，访问过变为实心，当前页面带外圈；两端页面都访问过时，其连接线变亮。使用抽象网络而不重复首页的大脑造型。图形表达网站探索足迹，不表达神经恢复或治疗效果。
2. **海底珊瑚。** 每个导航组一束珊瑚，每个页面一个枝梢；访问后局部染色。更贴合海洋视觉，也最接近“花园成长”的直观感受，但与 ORCA 的 RNA 编辑研究联系较弱。
3. **玻片收藏。** 保留首页五张玻片，每个页面对应片中的一颗示意细胞，访问后染色，标签显示该组探索数量。最自然地延续当前首页，也适合在不增加另一张目录的情况下渐进接入。

初始示例是 4/19，不代表任何实际访客记录。三个方向共享演示状态。点击页面节点或列表项会模拟一次访问；重复点击不重复计数。目录组按钮仅切换分类，不标记该组全部页面。图形属于导航示意，不是实验图像。

## 放置建议

完整视图放在首页尾部 Explore 区域，接在首页叙事之后、页脚之前。让它与现有目录共用同一组页面，避免重复一套导航。记忆星图版本可把现有玻片作为分类选择，星群作为足迹展示；玻片收藏版本直接增强现有玻片。

内页仅设轻量的“探索足迹 · n/19”入口，打开同一足迹视图或返回首页的对应锚点。优先放在内页末尾的下一步阅读区，之后再评估是否需要导航常驻入口。不要占用已有阅读进度的位置，也不要自动弹窗。

阅读过程：进入首页看到尚未探索的点 → 打开任意内页 → 该页记为已探索 → 返回后看到相应点或玻片染色 → 自由选择下一页。所有页面始终可以访问，不要求按顺序，也不设“读完才解锁”。

状态文案建议使用“已探索”，因为访问记录不能确认认真阅读。如确实需要“已读”，应提供用户主动标记或单独定义完成条件，而不是从打开页面推断。

## 后续接入边界

正式实现建议新增独立组件、样式、脚本；页面清单复用 NAVIGATION，使用稳定页面 ID，合并 hash、尾斜杠和重复访问。仅在有效正文页面记录一次访问，不把预览、错误页和首页滚动动画算成阅读完成。

跨页状态存本地浏览器，刷新和跨页保持；存储不可用时退化为本次会话，不影响访问。首页模板与布局的任何接入都需按 AGENTS.md 取得共享锁、重读实时 diff，再做小补丁。不能把本预览整页覆盖到首页，也不提升 `/next` 或 `/next-journey`。

静态/无脚本版本保留所有真实链接，手机视图把密集星图排成章节列；支持键盘、明确页面名称和文字状态。颜色之外同时使用空心、实心、外圈和文字。
