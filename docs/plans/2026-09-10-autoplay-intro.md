# ORCA 自动开场与连续下潜修复计划

**Goal:** 页面加载自动完成鱼群入场、大鱼停稳与 ORCA 显现；滚动只驱动小鱼接棒和下潜，同时修复三个已确认问题。

**Architecture:** 保留 Flask/Jinja 和原生 SVG/RAF。用约 4 秒的独立开场时钟驱动原时间线的 0–0.46 段；滚动进度 0–1 映射至后半段 0.46–1。提前滚动直接完成开场，不锁滚动；返回页首不重播。关闭/隐藏页面暂停时钟，减少动态效果立即显示静态版。

**Tech Stack:** Flask, Jinja, SVG, CSS, native JavaScript, Python unittest, Playwright；使用 `xbx_env`。

## 1. 先建立失败证据

- `tests/intro_autoplay.py`：不滚动也能观察入场→停稳→标题、副标题出现；小鱼不自行下潜，返回页首不重播。
- `tests/intro_composition.py`：保留连接点相差 31px 的失败测试，增加共享线宽与透明过渡检查。
- `tests/test_audit.py`：拒绝 SVG `href`、`xlink:href` 外部素材及缺失本地图片，允许内部片段。
- 运行相关测试，确认失败来自当前缺陷。

## 2. 修复审计

- `scripts/audit_build.py` 解析 SVG 图片和引用节点的两种 href；审计本地素材是否存在；识别协议相对外域 URL。
- 重跑审计单元测试，再冻结站点检查真实产物。

## 3. 修复连接

- 新建 `wiki/components/intro/ribbons.html` 共享丝带绘制宏。
- `neural.html` 与 `home_content.html` 共用线宽、颜色和横向偏移。
- 正文路径起点改为 (430, 0)，起始方向延续神经路径末端；SVG top 为 0。
- `intro.css` 的过渡背景透明，避免覆盖鱼身；重叠高度依据实际舞台高度，兼容矮窗口。
- 检查桌面/手机关键帧和连接测试。

## 4. 自动开场

- `static/intro.js` 分离开场时钟与滚动进度，素材准备后启动时钟。
- 大约前 2.3 秒完成入场，随后标题与副标题依次显现，总长约 4 秒。
- 小鱼在滚动后进入，镜头仅随滚动移动；等待时保留轻微漂浮。
- 页面隐藏暂停，提前滚动、锚点进入、跳过、动态效果偏好切换不锁住页面。
- 更新旧时间线测试的断言，保留倒放、响应式和无 JS 检查。

## 5. 验证与交接

- 运行 unittest、自动开场测试、三端时间线、构图、偏好切换、浏览器回归和独立性能采样。
- 构建并审计全部页面，检查截图而非只看绿色测试。
- 更新 `docs/ORCA_HOMEPAGE.md` 的时间线说明。
- 保留当前其他工作树改动，不改用户调整的 app.py 端口；不提交或推送未经检查的内容。
