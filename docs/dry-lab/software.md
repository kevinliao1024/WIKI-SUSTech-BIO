## Tools

The Brain Delivery Model provides forward simulation, candidate-panel aggregation and comparative design screening. The PUF-OffTarget Atlas provides transcriptome scans, candidate inspection and downloadable reports. Both tools expose their inputs, warnings and outputs for review.
