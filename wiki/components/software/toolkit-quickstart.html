Extract REWIRE_model_toolkit and use Python 3.12.

macOS / Linux 
cd REWIRE_model_toolkit
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-core-tested.txt
python main.py --help
python smoke_check.py
Windows · PowerShell 
cd REWIRE_model_toolkit
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-core-tested.txt
.venv\Scripts\python.exe main.py --help
.venv\Scripts\python.exe smoke_check.py

The smoke check uses a one-hour, three-timepoint fixture and six contract tests. Full analyses and the optional dashboard are documented in the package.
