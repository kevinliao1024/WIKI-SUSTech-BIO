1.1Overview

GVE and SNE showed fewer RNA-seq candidate sites than PUF12 while retaining apparent C388 signals. Programmable RNA editors need to combine target activity with control over editing elsewhere in the transcriptome. Module 1 characterizes these two aspects through RNA sequencing (RNA-seq), producing replicate-supported candidate sites and comparative editing profiles. These outputs inform PUF modeling, APOBEC variant analysis and the design of downstream LAMAR-based prioritization.

Our analysis identifies editor-associated C-to-U candidates while accounting for read quality, genetic variation and control background. Shared coverage requirements and replicate-level measurements define the editor comparison and guide site prioritization.

Transcriptome-wide RNA editing has also been reported for APOBEC-containing DNA base editors (Grünewald et al., 2019; Zhou et al., 2019). These findings motivate measuring RNA changes beyond the intended target in our PUF-directed system.

Specificity evaluation pairs editing breadth with retained target signal. We interpret candidate-site counts alongside the three monitored positions to assess recognition-domain and catalytic-domain changes.

This transcriptome-wide assessment complements the local assays in Module 2 and Module 3 and provides RNA-seq-derived training inputs for Module 4.

1.2Experimental design

We analysed 36 paired-end RNA-seq libraries generated from human HEK293T cells in our wet-lab experiments. The study comprised nine groups, each with four biological replicates.

GVE and SNE carry PUF mutations, whereas 132D and E72A carry APOBEC mutations. We therefore interpret changes in these two components separately.

Component Configuration
Editor treatments PUF10, PUF12, 132D, E72A, GVE and SNE
Background controls Control/mock, APOBEC-only and PUF-only
Reference Human GRCh38 primary assembly with matching GENCODE v50 annotation
Candidate substitutions Genomic C>T on the positive transcript strand and G>A on the negative transcript strand
Comparison scope Positions with REF + target ALT depth ≥20 in all 36 libraries

1.3Workflow

Alignment and allele recounting establish read support, while SNP and strand filters define the eligible sites. Control comparisons establish background signal, and agreement across four treated replicates tests repeatability. Sites passing these checks form the retained candidate set.

Read preprocessing and alignment

We removed paired-end Illumina adapters with fastp and retained its QC reports (Chen et al., 2018). Additional quality, length and poly-G filtering were disabled because read-quality selection was applied during allele counting.

STAR aligned reads to GRCh38 using the matching GENCODE v50 annotation, --twopassMode Basic and --sjdbOverhang 149 for 150-nt reads (Dobin et al., 2013). GATK MarkDuplicates and SplitNCigarReads prepared coordinate-sorted alignments for site analysis (McKenna et al., 2010). The GENCODE annotation framework and release 50 files are documented separately (Mudge et al., 2025; GENCODE, 2026). SplitNCigarReads processes splice-spanning alignments by splitting reads at skipped reference regions (GATK Team, 2022).

Candidate detection and annotation

REDItools2 identified candidate positions with -S -me 5 -bq 31 -q 31 -men 1 (Flati et al., 2020). Because -me measures total non-reference support, we recounted target alleles in every library using BQ ≥31, MAPQ ≥31 and NH=1. Unique-alignment tags were checked after preprocessing. The original REDItools suite introduced high-throughput RNA-editing detection from sequencing data (Picardi & Pesole, 2013); this workflow uses its later REDItools2 implementation.

Recounting excluded duplicate, secondary, supplementary, QC-failed and unmapped reads, together with deleted, skipped and non-ACGT observations. Ensembl VEP, using an offline GRCh38 cache, identified transcript-compatible C>T and G>A candidates (McLaren et al., 2016).

Genetic and sequence filtering

We excluded exact chromosome–position–REF–ALT matches to four HEK293T SNP catalogues after hg18-to-GRCh38 liftover and reference-allele checks. Each candidate required an unambiguous, transcript-oriented 101-nt sequence centred on cytosine. Low-complexity filtering required entropy ≥1.2, a homopolymer run <20 and a dinucleotide-repeat fraction <0.8.

Background screening

Each control group required a median allele rate ≤0.02, median absolute deviation ≤0.02 and no formal caller detections. The APOBEC-only−Control and PUF-only−Control median differences each had to be ≤0.02. These gates permit low ALT counts; missing observations remain missing.

One-sided pooled-read Fisher tests compared each treatment with the three controls. The largest p-value per site underwent Benjamini–Hochberg correction across the eligible comparison set, with FDR ≤0.05 required (Benjamini & Hochberg, 1995). The pooled-read statistic defines the screening gate; biological replication is assessed through the four-replicate detection and rate requirements.

Site selection and editing quantification

Retained sites required formal detection in all four treated replicates, with target ALT ≥20, depth ≥100 and allele rate ≥0.005 in each. The median absolute deviation of treated rates had to be ≤0.05.

Replicate rates were calculated as target ALT / (REF + target ALT). Each site was reported as the median of four replicate rates, without background subtraction. Target positions C295, C388 and C871 are quantified separately, requiring depth ≥100 in all four treated replicates without the ALT20 gate. This preserves low target measurements. C388 is excluded from candidate-site counts, whereas C295 and C871 are not systematically excluded.

Representative tool calls

These commands cover preprocessing, alignment and candidate calling. Shell variables represent sample files, references and new output paths; THREADS specifies allocated CPU threads.

Adapter trimming with fastp. The two adapter sequences match the paired-end library configuration. Quality selection is deferred to candidate calling and recounting.

fastp -i "$R1" -I "$R2" -o "$TRIMMED_R1" -O "$TRIMMED_R2" \
  --adapter_sequence AGATCGGAAGAGCACACGTCTGAACTCCAGTCA \
  --adapter_sequence_r2 AGATCGGAAGAGCGTCGTGTAGGGAAAGAGTGT \
  --disable_quality_filtering --disable_length_filtering --disable_trim_poly_g \
  --thread "$THREADS" --json "$QC_JSON" --html "$QC_HTML"

Splice-aware alignment with STAR. This example uses gzip-compressed reads, a GRCh38 index and matching GENCODE annotation. Two-pass alignment uses detected splice junctions; sjdbOverhang 149 matches 150-nt reads. Alignment tags and read groups preserve evidence needed downstream.

STAR --runThreadN "$THREADS" --genomeDir "$STAR_INDEX" \
  --readFilesIn "$TRIMMED_R1" "$TRIMMED_R2" --readFilesCommand zcat \
  --twopassMode Basic --sjdbGTFfile "$GTF" --sjdbOverhang 149 \
  --outSAMtype BAM SortedByCoordinate --outSAMattributes NH HI AS nM MD \
  --outSAMmapqUnique 60 \
  --outSAMattrRGline "ID:$READ_GROUP" "SM:$SAMPLE" "LB:$LIBRARY" PL:ILLUMINA \
  --outFileNamePrefix "$STAR_PREFIX"

Candidate calling with REDItools2. PREPARED_BAM denotes an indexed BAM after duplicate marking, splice processing and uniqueness-tag checks. REDITOOLS_SCRIPT is the installed script path, and FASTA is the indexed GRCh38 reference.

python2 "$REDITOOLS_SCRIPT" \
  -f "$PREPARED_BAM" -r "$FASTA" -o "$CALLS_TSV" \
  -S -q 31 -bq 31 -me 5 -men 1

Here, -S retains positions with mismatches, while -q and -bq set mapping and base quality thresholds. -me 5 requires total non-reference support; -men 1 avoids rejecting a position solely because another mismatch type has fewer than five observations. Target-ALT support and transcript strand are evaluated separately.

1.4Results and interpretation

PUF12 combined broader editing with a distinct target profile

PUF12 produced the largest retained-site set, with 12,908 sites, whereas PUF10 produced 2,774. Their median rates across retained sites were 13.99% and 12.75%, respectively. PUF12 therefore combined a broader detected profile with a modestly higher median across its retained set.

Candidate counts describe editing breadth, while each median summarizes rates within an editor-specific retained set. Target measurements provide the complementary endpoint: how much signal remains at the monitored positions.

Earlier REWIRE work reported improved specificity for an engineered ten-repeat PUF configuration relative to an eight-repeat configuration (Han et al., 2022). Our PUF12–PUF10 comparison challenges extending that result into a general rule that longer PUF domains continually reduce off-target editing. Under our common screening procedure, the longer construct instead produced a broader candidate-editing profile.

Binding studies also show that repeat number has a non-monotonic relationship with affinity. Zhao et al. (2018) found peak affinity around nine or ten repeats in their tested PUF series, with lower affinity for longer constructs. Their results distinguish recognition length, binding affinity and sequence discrimination, which need not improve together.

PUF10 and PUF12 had similar apparent C295 rates, at 42.17% and 41.34%, while PUF10 had a higher C871 rate, at 75.10% versus 63.50%. Their different target profiles accompany the difference in candidate-site breadth, making both endpoints relevant to construct selection.

We propose a balance between base-specific repeat–RNA recognition and interactions that contribute binding energy with less sequence discrimination. In this hypothesis, the published eight-to-ten-repeat improvement could reflect a net benefit from additional sequence-specific recognition. For our ten-to-twelve-repeat comparison, extra contacts or altered scaffold geometry might instead permit imperfectly matched RNAs to engage the editor. Such permissive recruitment could outweigh the benefit of additional base-specific contacts. The proposed shift remains a mechanistic interpretation; our libraries contain no PUF8 editor group and do not measure either contribution directly.

PUF12 also had a higher apparent C388 signal than PUF10, at 81.01% versus 73.23%, alongside its higher retained-set median. The combination of broader editing and higher signals is compatible with increased effective engagement of RNA substrates. C388 includes endogenous reference T, and the lower C871 signal shows that the change was site dependent. Editor abundance, RNA accessibility and catalytic activity remain alternative contributors to the observed profile.

APOBEC variants showed reduced detectable activity

The APOBEC variants 132D and E72A showed lower measurements across the three monitored positions. We compared both configurations with PUF12.

The 132D group retained 197 sites, with apparent C295, C388 and C871 rates of 3.11%, 36.44% and 18.65%. E72A had no retained candidate sites and low rates at all three positions, ranging from 0.05% to 0.32%. These APOBEC profiles coupled smaller candidate sets with lower monitored signals, consistent with attenuated detectable activity.

The residual 132D signal provides a starting point for assessing target retention after catalytic-domain changes. The E72A profile emphasizes the importance of preserving activity during APOBEC engineering.

PUF variants shifted the balance between site breadth and target signals

The PUF variant GVE retained 383 sites, approximately 97.0% fewer than PUF12, while showing an apparent C388 rate of 64.98%. Its C295 and C871 rates were lower, at 19.78% and 6.20%. GVE therefore provides a narrower detected profile accompanied by a retained C388 signal.

SNE retained 4,389 sites, approximately 66.0% fewer than PUF12, with an apparent C388 rate of 76.91%. Its C295 and C871 rates were 17.83% and 28.28%, respectively. Compared with GVE, SNE showed a higher apparent C388 signal but a larger candidate-site set and higher C871 activity. GVE thus favors a smaller screened set, whereas SNE offers a higher observed apparent C388 signal.

GVE and SNE support distinct engineering objectives: GVE offers a smaller screened set, while SNE retains a higher apparent C388 signal. Apparent C388 includes endogenous reference T. These descriptive HEK293T profiles integrate construct behaviour with expression, coverage and the shared screening procedure.

Sequence context was partly conserved across editor groups

Guanine remained prominent at position −1 in every non-empty editor set. This shared feature suggests that the variants retained a common local sequence bias despite differences in activity and site numbers. The GVE logo showed less pronounced −1 guanine dominance and a more visible −2 adenine component, suggesting a context shift worth testing.

The central cytosine reflects site selection, and the logos describe flanking-base composition within each retained set. The shared −1 pattern and the GVE shift guide further context comparisons.

We propose that the conserved local motif partly reflects the sequence preference of the engineered APOBEC catalytic domain. Published ProAPOBEC comparisons show that changing the catalytic scaffold changes local sequence preferences, including activity in GC contexts (Han et al., 2025). This provides a biological basis for considering APOBEC preference when interpreting the shared −1 guanine pattern.

The logos describe the immediate context of edited cytosines, rather than the complete RNA sequence recognized by PUF. A shared local motif can therefore persist even when PUF variants alter which transcripts or sites the editor encounters. The GVE context shift leaves open a contribution from recognition-domain changes to the composition of retained sites. These observations support separating catalytic context preference from RNA recruitment, but do not establish that PUF has little influence or quantify either domain's contribution.

Module 3 tests local RNA-context preference alongside retained activity. Transcript-oriented sequence windows also provide a consistent site representation for Module 4, where RNA-seq-derived labels support sequence-based prioritization.

Chromosome normalization supported broadly distributed candidate editing

We compared chromosome profiles against a fixed reference of 899,942 callable cytosines defined using PUF12 and the three control groups. The reference required depth ≥100 in four PUF12 replicates and ≥20 in all twelve controls, together with quality, strand, SNP and sequence filters. Each editor's retained sites were intersected with this reference before normalization.

For editor g and chromosome c, let N(g,c) denote retained candidates within the reference and C(c) the number of reference cytosines. The plotted value is:

Normalized share(g,c) = 100 × [N(g,c) / C(c)] / Σk [N(g,k) / C(k)]

The sum includes chromosomes with a non-zero reference denominator. Normalization adjusts for measurable cytosines, then scales each editor's relative candidate-density profile to 100%.

PUF10, PUF12 and SNE showed broadly distributed profiles, with normalized shares ranging from approximately 3.1% to 5.7%. Candidate densities extended across callable regions of the autosomes, including chromosome 19, and X.

The smaller 132D and GVE sets were more uneven, reaching their highest shares on X (7.8%) and chromosome 22 (7.6%), respectively. These peaks represented 17 and 14 candidate sites, making their descriptive profiles sensitive to sampling variation.

1.5Engineering implications

The six-editor comparison defines a joint selection objective: retain the intended target signal while narrowing the broader candidate profile. Shared-site comparisons clarify how candidate-set changes relate to editing rates.

1.6Reproducibility and availability

The Module 1 repository contains the RNA-seq workflow specification, recorded analysis settings, component environment files and postprocessing utilities, together with tests, supporting summary tables, Wiki figures and editable workflow artwork. These materials allow readers to inspect the analysis requirements, check the published summaries and reuse the documented utilities with compatible inputs. Raw sequencing reads, BAM files and machine-specific orchestration are excluded, so a complete end-to-end rerun requires additional data and deployment resources.
