Reproducibility

Start from one public source snapshot.

  • Record the Git commit and data versions.
  • Archive resolved parameters and input checksums.
  • Keep warnings beside outputs.
  • Distinguish missing evidence from zero.
  • Re-run automated tests before reporting.
  • Describe hardware and runtime for large scans.
